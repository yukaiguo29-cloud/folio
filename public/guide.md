# 欢迎来到知间 · Folio

## 让阅读回归阅读

打开一本书，开始一段思考。Folio 是一个离线优先的个人文档阅读空间。这里没有账号、没有推荐信息流，也没有自动上传的文档。

这份指南本身就是一份真实的 Markdown 文档。你可以选择本段文字，高亮它，添加一条批注，或者把它收藏到「灵感收集箱」。所有记录都会保存在本机的 SQLite 资料库。

> 阅读不是为了填满时间，而是为了给思考留出空间。

## 从你的文件开始

按 **Ctrl + O**（macOS 使用 Command）打开 PDF、EPUB、DOCX、TXT、Markdown 或 HTML 文件，也可以直接把文件拖入窗口。资料库支持一次导入多个文件以及整个文件夹。相同内容会通过 SHA-256 检测，不会重复创建记录。

桌面版本默认引用原文件。浏览器运行版本会在 IndexedDB 中保存文件副本。清除浏览器站点数据会删除这些副本，请保留原文件并定期导出数据库备份。

## 把文字变成自己的思考

选中文本，会出现高亮、下划线、批注、复制和灵感收藏工具。右侧「笔记」自动汇集当前文档的记录。点击记录，可以回到对应页面或章节。

PDF 的标注使用独立的本地标注层，不会修改原 PDF。可重排文档会通过选中文本、上下文和文字偏移恢复高亮，改变字号后仍能显示。

右上角可以切换主题。设置中可调整字体、字号、行距、页边距和阅读宽度。这些排版设置适用于文本、Markdown、HTML、EPUB 和 DOCX；PDF 始终保持原始页面。

## 少一点操作，多一点专注

使用 **Ctrl + K** 打开「专注指挥中心」。输入文档名称、笔记内容或标签进行搜索，也可以试试这些命令：

- 切换深色主题
- 开启沉浸阅读
- 查看全部高亮
- 开启阅读尺
- 跳转第 2 页

使用阅读工具栏可切换连续与分页阅读。PDF 支持缩放、单双页与缩略图。按左右方向键可以翻页。右上角的双栏按钮可以打开另一份文档，两个阅读位置独立保存。

## 建立一座小小的书架

在左侧创建「书架与工作台」，再从文档详情中加入相应文档。每份文档可以设置多个标签，并标记未读、阅读中、已完成。

灵感收集箱保留跨文档的摘录、来源、页码和时间。你可以把笔记或灵感导出为 Markdown，带到任何其他笔记工具。

阅读足迹使用真实的前台活动计时。长时间没有操作时停止累计；空资料库不会显示虚构的阅读成绩。

## AI，由你决定何时出现

AI 默认关闭。在设置中启用并配置 OpenAI 兼容接口或本地 Ollama 后，可以解释选文、提炼观点、翻译，或根据关键词检索的原文提问。

每次发送前，你都会看到目标服务、问题与提供的原文。模型回答中的页码引用可以跳回原文，但回答仍需由你结合原文判断。API Key 仅存在于当前会话，不进入数据库备份。

## 数据与边界

- 资料库、笔记、设置和进度保存在 SQLite 中。
- 设置 → 本地资料库可以导出和恢复数据库备份。备份不包含原文件。
- DOCX 使用流式排版，复杂 Word 页面、页眉页脚和修订无法完全还原。
- 扫描 PDF 可以阅读，但尚不包含 OCR。加密 PDF 需要先解除密码。
- EPUB 使用真实章节解析，原书复杂 CSS 会过滤为统一的阅读样式。
- 删除资料库记录会删除相应笔记，需要明确确认；原文件不会被删除。

**愿你每次打开 Folio，都能遇到一段值得停下来的文字。**
